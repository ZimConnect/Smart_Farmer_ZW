Smart Farmer ZW Pro v1.0

Zimbabwe-focused Android Flutter app for livestock, breeding, crops, horticulture, farm calendars and finance.

🚀 Launch Web App 📥 Download APK

🌾 Quick Actions

FEATURE 1

🐄 Livestock Management

  • Cattle: Mashona, Tuli, Brahman, Hereford, Angus, Simmental, Jersey, Holstein, Ayrshire
  • Small Stock: Pigs, goats, sheep, rabbits
  • Poultry: Broilers, layers, roadrunners, turkeys, ducks, geese
  • Other: Dogs and horses
  • Fish: Tilapia/bream and catfish/muramba
FEATURE 2

🌱 Crops & Horticulture

  • Full crop/horticulture catalogue
  • Planting calendars for ZW seasons
  • Fertilizer and pesticide guides
  • Breeding & gestation calculators
  • Feed formulation tools
FEATURE 3

📅 Finance & Planning

  • Farm income & expense tracking
  • Profitability per animal/crop
  • Reminders for vaccination, dipping
  • Market price tracker
  • Offline mode for rural areas

📲 How to Install

1. Click Launch Web App above to use it on phone browser.
2. Or clone repo: git clone https://github.com/ZimC/Smart_Farmer_ZW.git
3. Then: flutter pub get && flutter run
